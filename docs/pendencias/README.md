# Pendências

O que falta para fechar o v1 e depende de alguém fazer algo fora do código. Cada item diz o que fazer, em que ordem, e o que ele fecha. A situação de todas as tarefas está em [`tasks/`](../../tasks/README.md).

| Pendência | Depende de | Fecha |
|---|---|---|
| [Agentes reais no Linux (WSL)](agentes-reais-no-linux.md) | Você logar o Claude Code e o Codex no WSL | Tarefa 0.4 |
| [Validação na máquina Linux real](validacao-no-linux-real.md) | A máquina Linux, com os dois agentes logados | Tarefa 6.3 |
| [Instalar a release em máquina limpa e publicar](primeira-release.md) | Uma máquina limpa de cada sistema | Tarefa 6.1 |
| Confirmar a prioridade dos sinais do Codex | Seu "de acordo" | Item 1.1 de [`DECISOES-E-RISCOS.md`](../../DECISOES-E-RISCOS.md) |

Quando um item for concluído, apague o arquivo dele e a linha da tabela, e marque a tarefa em `tasks/`.
